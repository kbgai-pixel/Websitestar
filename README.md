# TGIS Website

This is a mobile-first single-page website for TGIS, featuring a clean brand-focused layout with sections for About us, Book Me, Events, and Shop.

## Included features

- Logo on the left and hamburger menu on the right
- Top navigation with About us, Book Me, Events, and Shop
- Book Me button linking to a calendar page
- Hero section with service-focused messaging
- Event cards and product catalog layout
- Product list stacked vertically, one item per row
- Centered footer links for easy tapping on mobile
- Responsive design for desktop and smaller screens

## Files

- `index.html` — main page content and structure
- `styles.css` — entire visual design and responsive behavior
- `script.js` — mobile menu toggle behavior

## How to view the site

Open `index.html` in any browser to view the website locally.

If you want to preview it in VS Code, use the Live Preview extension or simply open the file in a browser.
